Configurações do app

Ao trocar o endereço, o app reinicia.

Atalho global

Toque no atalho para digitar. Segure enquanto fala para ditar, e solte para transcrever.

Voz (transcrição no computador)

O áudio é transcrito pelo Whisper no próprio computador e nunca é enviado ao servidor. Baixe um modelo uma vez para usar a voz.

Esta versão do app foi gerada sem reconhecimento de voz.
